# California parishes recovered via Wayback

The `ca-<diocese>/` folders hold California parish sites whose own pages could not be read live (Cloudflare challenge, 403, dead). They are here so the `wayback` job can recover archived copies; the private app repo merges the results back into data/real/california/sites. Same privacy rules as everything else here.
